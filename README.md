# To-Do App (Java)

A console to-do list app built with Java.

## Features
- Add tasks with priority (High/Medium/Low) and due date
- Overdue warnings
- Tasks sorted by status and priority
- Mark done and delete
- Stats (done, pending, overdue, completion %)
- Tasks saved to a file automatically

## How to run
Open in IntelliJ IDEA and run Main.java.
